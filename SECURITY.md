# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | ✅ Yes     |
| 1.0.x   | ⚠️ Critical fixes only |
| < 1.0   | ❌ No      |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email: ag.chaudhari.1512@gmail.com  
Subject line: `[forgeSDLC SECURITY] <brief description>`

Include:
- forgeSDLC version and transport (MCP server / Electron)
- Steps to reproduce
- Impact assessment if known

You will receive an acknowledgement within 48 hours.
Confirmed vulnerabilities will be patched and disclosed within 30 days.
